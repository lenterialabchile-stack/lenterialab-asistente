# LenteriaLab - Asistente IA

Proyecto de automatización de atención comercial para LenteriaLab.

## Cómo funciona

Landing → n8n → OpenAI → clasificación → respuesta automática o derivación a humano → Google Sheets.

## Herramientas

- n8n
- OpenAI
- Vercel
- Google Sheets
- GitHub

## Landing

https://lenterialab.vercel.app/

## Archivos principales

- `index.html`: landing del asistente
- `LenteriaLab-Atencion-IA-v1.json`: workflow de n8n
